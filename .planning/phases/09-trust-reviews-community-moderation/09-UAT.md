# Phase 9 UAT Tracker: Trust, Reviews & Community Moderation

### Test 1: Product Ratings & Reviews Section
- **Action:** Open any product details page on `/marketplace` (e.g. `/product/<id>`).
- **Expected Result:** Below the product details, a dedicated **Customer Reviews & Ratings** section appears with star score, rating breakdown bars, and "Write a Review" button.
- **Status:** Pending User Confirmation

### Test 2: Write a Review Modal
- **Action:** Click "Write a Review" on the product details page.
- **Expected Result:** Opens the interactive rating modal with hoverable star selector (1–5★) and comments textarea.
- **Status:** Pending User Confirmation

### Test 3: Report Listing / Seller Modal
- **Action:** Click the "Report" flag icon in the breadcrumb header on the product details page.
- **Expected Result:** Opens the Community Report modal with structured violation categories (Misleading info, Counterfeit goods, Price gouging, Inappropriate content). Submitting a report shows confirmation.
- **Status:** Pending User Confirmation

### Test 4: Admin Moderation Dashboard
- **Action:** Navigate to `/admin` and click the **Reports** tab.
- **Expected Result:** Displays all submitted community reports with status badges and "Resolve" / "Dismiss" moderation action buttons.
- **Status:** Pending User Confirmation
